# Kisan Jod Earn — Frontend Only

This ZIP contains the standalone browser frontend for the Kisan Jod Earn interactive mobile-style website.

## Included

| File | Purpose |
|---|---|
| `index.html` | Website structure and browser entry point |
| `styles.css` | Responsive mobile-style visual system |
| `app.js` | Interactive navigation, task actions, language picker, demo feedback, and view state |
| `assets/kisan-jod-earn-icon.png` | Local Kisan Jod Earn icon asset |

## Excluded

This archive intentionally excludes the database, backend/API routes, authentication, server runtime, deployment settings, environment variables, and package manager files.

## Run locally

Open `index.html` directly in a modern browser. For the most consistent browser behavior, serve this folder with any static-file server, such as the Live Server extension in VS Code.

The website is a frontend demonstration with local in-browser interaction. It does not connect to live farmer, inventory, dispatch, or payment data.
